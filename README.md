## 설치

중간에 macOS 가 한 번 막습니다. 고장이 아니고, **처음 한 번뿐**이에요.

**1.** 위 단추로 받으면 다운로드 폴더에 **SideNote** 앱이 생깁니다.
   압축이 그대로 남아 있으면 `SideNote.zip` 을 두 번 눌러 풀어 주세요.

**2.** **SideNote 를 두 번 누릅니다.** *"Apple 이 확인할 수 없습니다"* 라는 창이 뜹니다.
   App Store 를 거치지 않은 앱을 처음 열 때 나오는 안내예요. **완료** 를 눌러 창을 닫습니다.

> ⚠️ **"휴지통으로 이동" 은 누르지 마세요.** 앱이 지워집니다.

**3.** **시스템 설정 → 개인정보 보호 및 보안** 을 엽니다. 아래로 내리면
   *"Mac 을 보호하기 위해 차단했습니다"* 라는 줄이 있어요. 옆의 **"그래도 열기"** 를 누릅니다.
   (macOS 버전에 따라 **"확인 없이 열기"** 로 적혀 있을 수도 있습니다.)

**4.** 확인 창이 한 번 더 뜨면 **열기** 를 누릅니다. 암호나 Touch ID 를 요구하면 확인해 주세요.

**5.** 앱이 **"응용 프로그램 폴더로 옮길까요?"** 라고 물으면 **옮기기** 를 누릅니다.
   옮긴 뒤 앱이 다시 열립니다. **끌어다 놓으실 필요 없습니다.**

### 열렸는데 아무것도 안 보이나요?

정상입니다. SideNote 는 **Dock 에 아이콘이 없습니다.**
화면 **오른쪽 위 메뉴바**의 체크리스트 아이콘과, 화면 **오른쪽 끝**의 얇은 색 선 4개로 씁니다.
`⌃` + `⌥` + `N` 을 눌러도 열립니다.

그래도 열리지 않으면 [설치가 안 될 때](https://innervaworld.github.io/sidenote-releases/trouble.html) 를 봐 주세요.

## 쓰는 법

화면 오른쪽 끝에 얇은 색 선 네 개가 있어요. 마우스를 가까이 대면
**Today · Tomorrow · Month · Memo** 가 펼쳐집니다. 눌러서 열면 됩니다.

`⌃` + `⌥` + `N` 으로도 열고 닫을 수 있어요. 메뉴바 아이콘을 눌러도 같습니다.

메뉴바의 체크리스트 아이콘은 **왼쪽 클릭이 열기·닫기**, **오른쪽 클릭이 설정**입니다.

### 패널 안에서

| 단축키 | 내용 |
|---|---|
| `⌘` + `N` | 새 항목 |
| `⌘` + `⇧` + `N` | 지금 줄에 메모 달기 |
| `⌘` + `↩` | 완료 표시 |
| `⌘` + `⌫` | 줄 지우기 |
| `Esc` | 편집 끝내기 (한 번 더 누르면 닫힘) |
| `⌘` + `W` | 닫기 |

기호는 키보드에 있는 그대로예요.
`⌘` 커맨드 · `⇧` 시프트 · `⌃` 컨트롤 · `⌥` 옵션 · `↩` 엔터 · `⌫` 딜리트

줄에 마우스를 올리면 단추 세 개가 나타납니다. 메모를 달거나, 잡아서 순서를 바꾸거나,
더보기에서 복사·삭제를 할 수 있어요. 잡은 채로 위쪽 탭까지 끌면 그 목록으로 옮겨집니다.

로그인할 때 자동으로 켜지게 하려면 메뉴바 아이콘을 오른쪽 클릭해
**"로그인 시 자동 실행"** 을 켜 주세요.

## 업데이트

새 버전이 나오면 앱이 알아서 받아 둡니다. 하루에 한 번, 그리고 앱을 켤 때 확인해요.
받은 다음에는 스스로 바뀌고 다시 뜹니다.

기다리지 않고 지금 확인하려면 메뉴바 아이콘 오른쪽 클릭 → **"업데이트 확인…"**.
직접 챙기고 싶으시면 같은 메뉴에서 **"자동 업데이트"** 를 꺼 두셔도 됩니다.

## 백업과 옮기기

적어 두신 내용은 이 파일 하나에 들어 있습니다.

```
~/Library/Application Support/SideNote/notes.json
```

- 앱을 지워도 이 파일은 남습니다.
- 같은 폴더의 `Backups` 에 앱을 켤 때마다 한 벌씩 자동으로 쌓입니다. 최근 30벌까지 보관돼요.
- 다른 맥으로 옮기실 때는 이 파일만 같은 자리에 복사하면 그대로 따라옵니다.
  앱을 끄고 복사한 뒤 다시 켜 주세요.

구글 계정으로 로그인해 두시면 드라이브에도 한 벌 보관되므로, 따로 챙기지 않으셔도 됩니다.
