## 설치

1. 받은 `SideNote.dmg` 를 열고 **SideNote** 를 **응용 프로그램** 폴더로 끌어다 놓습니다.

2. 응용 프로그램 폴더에서 SideNote 를 두 번 누릅니다.

3. **"확인되지 않은 개발자" 라며 열리지 않습니다. 정상입니다.**
   Apple 에 등록비를 내지 않고 만든 앱이라 나오는 경고입니다.

   - **시스템 설정** → **개인정보 보호 및 보안** 을 엽니다
   - 아래로 내리면 *"SideNote 이(가) 차단되었습니다"* 가 있습니다
   - 옆의 **"확인 없이 열기"** 를 누릅니다

4. 이 과정은 **처음 한 번뿐**입니다. 이후 새 버전은 앱이 알아서 받아 바꿉니다.

## 쓰는 법

- 화면 오른쪽 끝 얇은 색 선 4개에 마우스를 대면 **Today / Tomorrow / Month / Memo** 가 펼쳐집니다. 눌러서 엽니다.
- 단축키 `⌃⌥N` 으로도 열고 닫습니다.
- 메뉴바 체크리스트 아이콘 — 왼쪽 클릭은 열기/닫기, 오른쪽 클릭은 설정입니다.
- 패널 안에서 `⌘N` 새 항목 · `⌘⇧N` 메모 달기 · `⌘↩` 완료 토글 · `Esc` 닫기
- 줄에 마우스를 올리면 메모 · 끌어서 이동 · 더보기 단추가 나옵니다.

로그인할 때 자동으로 켜지게 하려면 메뉴바 아이콘 우클릭 → **"로그인 시 자동 실행"**.

## 업데이트

하루에 한 번 새 버전이 있는지 확인하고 알아서 받습니다.
메뉴바 아이콘 우클릭 → **"업데이트 확인…"** 으로 즉시 확인하거나, **"자동 업데이트"** 를 꺼 둘 수 있습니다.

## 내가 적은 것은 어디에 있나

```
~/Library/Application Support/SideNote/notes.json
```

앱을 지워도 이 파일은 남습니다. 맥을 옮길 때 이 파일만 같은 경로로 복사하면 항목이 그대로 넘어옵니다.
