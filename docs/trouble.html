막히기 쉬운 곳부터 순서대로 적었습니다.

열었는데 아무것도 안 보입니다

가장 흔한 경우입니다. 대개는 이미 잘 열린 것입니다.

SideNote 는 Dock 에 아이콘이 없습니다. 창도 뜨지 않아요. 두 곳을 봐 주세요.

  • 화면 오른쪽 위 메뉴바 — 체크리스트 모양 아이콘 (배터리·와이파이 근처)
  • 화면 오른쪽 끝 — 얇은 색 선 4개. 마우스를 가까이 대면 펼쳐집니다

둘 중 하나라도 보이면 정상입니다. 선에 마우스를 대거나 ⌃ + ⌥ + N 을 눌러 보세요.

노트북에 노치가 있고 메뉴바 아이콘이 많으면, 새 아이콘이 노치에 가려 안 보일 수 있습니다. 다른 앱 아이콘을 ⌘ 를 누른 채 끌어 정리하거나, 화면 오른쪽 끝의 색 선으로 쓰시면 됩니다.

앱을 지웠다 다시 까신 경우, 처음 켤 때 뜨는 패널이 나오지 않을 수 있습니다. 아래를 터미널에 붙여넣으면 처음 켠 상태로 되돌리고 다시 엽니다. 적어 두신 내용은 지워지지 않습니다.

defaults delete com.local.sidenote didOnboard; pkill -x SideNote; open /Applications/SideNote.app

지우고 싶은데 "사용 중" 이라며 안 지워집니다

실행 중인 앱은 휴지통에 넣을 수 없습니다. 먼저 끄면 됩니다.

터미널(Spotlight 에서 터미널 검색)에 붙여넣고 return 을 누르세요. 끄고 지우는 것을 한 번에 합니다.

pkill -x SideNote; rm -rf /Applications/SideNote.app ~/Applications/SideNote.app

적어 두신 내용과 자동 실행 설정까지 남김없이 지우려면 아래도 실행하세요.

rm -rf ~/Library/Application\ Support/SideNote ~/Library/LaunchAgents/com.local.sidenote.plist
끄기만 하고 싶으시면 메뉴바의 체크리스트 아이콘을 오른쪽 클릭해 종료 를 누르셔도 됩니다.

"휴지통으로 이동" 을 눌러 버렸습니다

앱이 지워진 것뿐이라, 다시 받으면 됩니다.

휴지통에서 꺼내거나, 받는 곳에서 다시 내려받으세요. 이번에는 완료 를 누르고 시스템 설정에서 "그래도 열기" 를 누르시면 됩니다.

"그래도 열기" 를 눌렀는데 안 열립니다

응용 프로그램 폴더로 옮기지 않고 dmg 안에서 실행하면 생길 수 있습니다.

dmg 창의 앱을 응용 프로그램 폴더로 끌어다 놓은 뒤, 응용 프로그램 폴더에서 실행해 보세요. 그래도 안 되면 아래 진단을 돌려 주세요.

"손상되었기 때문에 열 수 없습니다"

파일이 실제로 망가진 것이 아니라, 격리 표시가 남아 생기는 일입니다.

터미널(Spotlight 에서 터미널 검색)에 아래를 붙여넣고 실행하세요.

xattr -cr /Applications/SideNote.app

그다음 응용 프로그램 폴더에서 다시 열어 보세요.

그래도 안 될 때 — 진단

무엇이 문제인지 알려 주는 명령입니다. 읽기만 하고 아무것도 바꾸지 않습니다.

curl -sSL https://innervaworld.github.io/sidenote-releases/diag.sh | bash

터미널에 붙여넣고 return 을 누른 뒤, 나온 결과를 그대로 보내 주세요.
