SideNote

화면 오른쪽 끝에서 슬라이드로 나오는 체크리스트

.dmg · Apple Silicon + Intel · macOS 13 이상 · 무료

설치

  1. 받은 SideNote.dmg 를 열고 SideNote 를 응용 프로그램 폴더로 옮겨 주세요.
  2. 응용 프로그램 폴더에서 SideNote 를 두 번 누릅니다.
  3. 열리지 않고 "Apple이 확인할 수 없습니다" 라는 창이 뜹니다. App Store 를 거치지 않은 앱을 처음 열 때 macOS 가 확인을 요청하는 절차예요. 완료 를 눌러 창을 닫습니다.
    이 창의 "휴지통으로 이동" 은 누르지 마세요. 앱이 지워집니다.
  4. 시스템 설정 → 개인정보 보호 및 보안 을 열고 아래로 내리면 "Mac을 보호하기 위해 차단했습니다" 라는 줄이 보입니다. 옆의 "그래도 열기" 를 누르세요. (macOS 버전에 따라 "확인 없이 열기" 로 적혀 있을 수도 있습니다.)
  5. 확인 창이 한 번 더 뜨면 열기 를 누르고, 암호나 Touch ID 를 요구하면 확인해 주세요.
  6. 여기까지가 처음 한 번입니다. 다음부터는 바로 열립니다.

쓰는 법

화면 오른쪽 끝에 얇은 색 선 네 개가 있어요. 마우스를 가까이 대면 Today · Tomorrow · Month · Memo 가 펼쳐집니다. 눌러서 열면 됩니다.

⌃ + ⌥ + N 으로도 열고 닫을 수 있어요. 메뉴바의 체크리스트 아이콘은 왼쪽 클릭이 열기·닫기, 오른쪽 클릭이 설정입니다.

단축키내용
⌘ + N새 항목
⌘ + ⇧ + N지금 줄에 메모 달기
⌘ + ↩완료 표시
⌘ + ⌫줄 지우기
Esc편집 끝내기 (한 번 더 누르면 닫힘)
⌘ + W닫기

기호는 키보드에 있는 그대로예요.
⌘ 커맨드 · ⇧ 시프트 · ⌃ 컨트롤 · ⌥ 옵션 · ↩ 엔터 · ⌫ 딜리트

줄에 마우스를 올리면 단추 세 개가 나타납니다. 메모를 달거나, 잡아서 순서를 바꾸거나, 더보기에서 복사·삭제를 할 수 있어요. 잡은 채로 위쪽 탭까지 끌면 그 목록으로 옮겨집니다.

여러 컴퓨터에서 쓰기

메뉴바 아이콘 오른쪽 클릭 → "구글 계정으로 로그인…" 을 누르면 적어 두신 내용이 본인의 구글 드라이브에 보관됩니다. 다른 컴퓨터에서 같은 계정으로 로그인하면 그대로 이어서 쓸 수 있어요.

내용은 사용자 본인의 드라이브에만 저장됩니다. 개발자의 서버는 없습니다. 자세한 내용은 개인정보처리방침에 있습니다.

백업과 옮기기

적어 두신 내용은 이 파일 하나에 들어 있습니다.

~/Library/Application Support/SideNote/notes.json

  • 앱을 지워도 이 파일은 남습니다.
  • 같은 폴더의 Backups 에 앱을 켤 때마다 한 벌씩 자동으로 쌓입니다. 최근 30벌까지 보관돼요.
  • 다른 맥으로 옮기실 때는 이 파일만 같은 자리에 복사하면 그대로 따라옵니다. 앱을 끄고 복사한 뒤 다시 켜 주세요.

구글 계정으로 로그인해 두시면 드라이브에도 한 벌 보관되므로, 따로 챙기지 않으셔도 됩니다.

업데이트

새 버전이 나오면 앱이 알아서 받아 둡니다. 기다리지 않고 지금 확인하려면 메뉴바 아이콘 오른쪽 클릭 → "업데이트 확인…" 을 누르세요.
