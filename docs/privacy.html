개인정보처리방침

SideNote · 2026년 8월 26일

SideNote 에는 개발자의 서버가 없습니다. 적어 두신 내용은 사용자의 맥과, 사용자가 직접 연결한 사용자 본인의 구글 드라이브에만 저장됩니다. 개발자는 그 내용을 수집하거나, 열람하거나, 제3자에게 제공하지 않습니다.

어떤 정보를 다루나

  • 사용자가 적은 체크리스트와 메모 — 항목의 글, 완료 여부, 날짜, 순서
  • 구글 계정 정보 — 구글 계정으로 로그인한 경우에 한해, 어느 계정으로 로그인했는지 보여 주기 위한 이메일 주소

그 밖에 이름, 연락처, 위치, 기기 식별자, 사용 기록 등은 수집하지 않습니다. 광고와 분석 도구를 쓰지 않으며, 추적하지 않습니다.

어디에 저장되나

  • 사용자의 맥 — ~/Library/Application Support/SideNote/
  • 사용자 본인의 구글 드라이브 — 구글 계정으로 로그인한 경우에만, sidenote-notes.json 파일 하나로 저장됩니다. 이 파일의 소유자는 사용자 본인이며, 사용자의 드라이브 용량을 사용합니다.

개발자의 서버로 전송되는 정보는 없습니다. 앱이 통신하는 곳은 구글(로그인과 드라이브)과, 새 버전이 있는지 확인하기 위한 GitHub 뿐입니다. 새 버전 확인은 공개된 릴리스 정보를 읽어 오는 것으로, 사용자의 정보를 보내지 않습니다.

구글 드라이브 권한

SideNote 는 구글에 drive.file 권한 하나만 요청합니다. 이 권한은 이 앱이 만든 파일만 다룰 수 있게 합니다. 사용자의 드라이브에 있는 다른 문서, 사진, 파일은 앱에 보이지 않으며 접근할 수도 없습니다.

SideNote 가 구글에서 받은 정보는 위에 적은 용도로만 씁니다. 다른 목적으로 쓰거나, 제3자에게 넘기거나, 광고에 활용하지 않습니다. 이는 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 따릅니다.

로그인 정보 보관

구글 로그인 후 받은 토큰은 사용자 맥의 키체인에 보관되며, 그 맥을 벗어나지 않습니다. 개발자에게 전송되지 않습니다.

지우고 싶을 때

  • 연결만 끊기 — 메뉴바 아이콘 우클릭 → "구글 계정 연결 해제". 저장된 내용은 그대로 남고 주고받기만 멈춥니다.
  • 드라이브에서 지우기 — 구글 드라이브에서 sidenote-notes.json 을 삭제하세요.
  • 권한 회수 — 구글 계정 권한 관리에서 SideNote 의 접근 권한을 언제든 해제할 수 있습니다.
  • 맥에서 지우기 — ~/Library/Application Support/SideNote/ 폴더를 삭제하세요.
